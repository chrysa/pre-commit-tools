# Glossary — pre-commit-tools

Terms as used in this repo. Tags: **FACT** unless noted.

- **Hook** — a single pre-commit check: a Python module in `pre_commit_hooks/` with a
  `main(argv) -> int` entry point, a console script, a manifest id, and a test file.
- **Manifest** — `.pre-commit-hooks.yaml`; the public contract consumers reference by
  `id`. 82 ids.
- **Entry point / console script** — `<hook-name> = pre_commit_hooks.<module>:main` in
  `pyproject.toml [project.scripts]`. Resolvable only after `pip install -e .`.
- **Extra** — an optional dependency group (`dead_code`, `format_dockerfile`, `yaml`,
  `ts_unreachable_code`, `screenshot`, `lint`, `typecheck`, `test`, `dev`) gating heavy
  hooks.
- **`PreCommitTools`** — shared arg-parsing/reporting helper (`tools/pre_commit_tools.py`);
  the mandated alternative to inline `argparse`.
- **Pattern detection** — regex-based detection base class (`tools/pattern_detection.py`)
  underpinning the `*-detection` hooks.
- **manual stage** — a pre-commit `stages: [manual]` hook that does not run on every
  commit (e.g. `python-dead-code`, `generate-changelog`); invoked with
  `--hook-stage manual`.
- **ADR gate** — `adr_gate.py`; fails a commit that should carry an ADR but doesn't.
- **Docs-drift gate** — `docs_drift_gate.py`; fails when docs fall out of sync with code.
- **Quality gate / regression gate** — `scripts/quality_gate.py` + `regression_gate.py`;
  compare current metrics to `.quality-gate-baseline.json`.
- **Context files** — `handover.md`, `ai-instructions.md`: generated by
  `scripts/gen_context_files.py` (chrysa ADR D-0012); do not hand-edit.
- **Claude-asset hooks** — hooks validating `.claude/` assets: skill/agent frontmatter,
  MCP config, CLAUDE.md facts, assets-present, managed-asset drift.
- **Screenshot sync** — `pre_commit_hooks/screenshot_sync/` + `screenshot_capture.py` /
  `screenshot_publish.py`; captures and publishes UI screenshots of *consumer* projects.
- **chrysa-quality-gate** — external package pulled over `git+ssh` from `chrysa-lib`
  for the dev/quality-gate extra.
- **APE v2** — project-scope hook under `.claude/ape/` (`ape-transform-v2`); added in
  commit #418. (INFERENCE: agent-prompt-engineering transform; full purpose in
  `.claude/ape/README.md`.)
- **STANDARDS.chrysa** — the canonical chrysa transverse standards; vendored under
  `standards/` and pointed to from CLAUDE.md.
